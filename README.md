# Thread & Wax Beauty Studio Website

Single-page white and gold beauty parlour website.

Sections:
- Home
- Service Menu
- Our Story
- Services
- Contact / Appointment Request

Files remain separated into HTML, CSS, JavaScript and SVG assets.

## V10 responsive update
The approved desktop design is preserved. Responsive rules were added for large laptops, tablets, mobile phones, very narrow screens, and touch devices. The mobile navigation closes safely when the viewport returns to desktop width.

V17 fixes:
- Cropped Logo.png transparent padding for better visible size.
- Added a subtle ivory/gold logo treatment in the header for clarity.
- Fixed menu category clipping caused by sticky rail/overflow interaction.
- Added anchor offsets so fixed header no longer covers section content.
- Preserved responsive horizontal menu navigation on mobile.

## V19 compact layout update
- Reduced Our Story artwork height and copy spacing.
- Tightened Services row height while keeping the same approved alternating layout.
- Reduced Menu, Contact, review/newsletter and footer vertical spacing.
- Added tablet/mobile compact sizing to shorten total page length without changing the visual identity.
